# Vinu Balagopal A P — Portfolio

Personal portfolio for [vinu.world](https://vinu.world), built with [Astro](https://astro.build) as a single static page and deployed to GitHub Pages by GitHub Actions.

The design follows the earlier hand-written site (`Portfolio-Website/legacy`): a light theme, 12px system font, the tilted name pill on the profile photo, the gradient "V-shape" headline, and white rounded cards.

## Page sections

| Section | Anchor | Content source |
|---|---|---|
| Profile, headline, impact numbers | `/` | `src/pages/index.astro`, `metrics` in `src/data/profile.ts` |
| Projects | `#projects` | `projects` in `src/data/profile.ts` |
| About | `#about` | Written directly in `src/pages/index.astro` |
| Experience | `#experience` | `experience` in `src/data/profile.ts` |
| Writing & Insights | `#blogs` | Medium RSS feed, fetched at build time |
| Contact (footer) | `#contact` | `src/pages/index.astro` |

The Skills & Tools and Education blocks are hidden inside a comment in the Experience section of `src/pages/index.astro`. To show them again, remove the comment wrapper and add `skills` to the import from `../data/profile` at the top of that file.

## Editing content

Most content lives in **`src/data/profile.ts`**:

- `site`: name, title, description, email, location, current company, education, and social profiles. These feed the page `<head>`, the structured data, and `/llms.txt`.
- `projects`: listed in display order. A project with an empty `links` array shows no links.
- `experience`: roles, newest first.
- `metrics`: the four impact numbers under the headline.
- `skills`: used only by the hidden Skills & Tools block.

The About text and the footer are written directly in `src/pages/index.astro`. Styles are in `src/styles/global.css`.

When your role, current company, or name changes, update `site` in `src/data/profile.ts`, then update the text constants at the top of `scripts/og-image.py` and regenerate the social share image:

```bash
pip install pillow   # once
python3 scripts/og-image.py
```

## Blog posts (Medium)

Posts are fetched from `https://medium.com/feed/@vinubalagopalap` **when the site builds**, not in the visitor's browser. Medium's feed can't be read cross-origin, and RSS-to-JSON proxies such as rss2json proved unreliable. If the feed can't be reached during a build, the page still builds and shows a "Visit Medium" message.

To pick up new posts without a code change, the deploy workflow also runs **every day at 03:00 UTC**. You can trigger it any time from **Actions → Deploy portfolio to GitHub Pages → Run workflow**.

## Run locally

Requires Node.js 22 or later.

```bash
npm install
npm run dev       # local dev server
npm run build     # production build into dist/
npm run preview   # serve the production build
npm test          # astro check: type and template diagnostics
```

## SEO, AEO, and GEO

- **Meta tags** (`src/pages/index.astro`): title, description, canonical URL `https://vinu.world/`, robots, theme colour, Open Graph (`og:type` profile), and X/Twitter large-image card.
- **Social share image:** `public/og-image.png` (1200×630 PNG, absolute URL), generated by `scripts/og-image.py`.
- **Structured data:** a JSON-LD `@graph` with `WebSite`, `ProfilePage`, `Person` (photo, email, region, current company, college, `sameAs` profiles), and a `SoftwareApplication` entry for each project.
- **Identity:** `rel="me"` links to LinkedIn, X, Medium, GitHub, and TradingView.
- **`/llms.txt`:** a plain-markdown summary for AI answer engines, generated from `src/data/profile.ts` by `src/pages/llms.txt.ts`, so it always matches the page.
- **`public/robots.txt`:** allows all crawlers, explicitly including AI crawlers (GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, Claude-User, PerplexityBot, Google-Extended, Applebot-Extended), and points to the sitemap.
- **`public/sitemap.xml`:** lists the home page. Add any new indexable page here.
- **`/dark-theme/`:** an archived earlier design (`archive/dark-theme/`). It is still published but marked `noindex` so it doesn't compete with the home page.

After the site is live on `vinu.world`:

1. Add the site to **Google Search Console** and **Bing Webmaster Tools** (Bing's index feeds ChatGPT search and Copilot), and submit `https://vinu.world/sitemap.xml`.
2. Check the structured data with Google's [Rich Results Test](https://search.google.com/test/rich-results).
3. Refresh the LinkedIn preview with [Post Inspector](https://www.linkedin.com/post-inspector/).
4. Link to `https://vinu.world` from your LinkedIn, GitHub, X, Medium, and TradingView profiles, so the identity links point both ways.

## Deployment

The portfolio is automatically built and deployed to [vinu.world](https://vinu.world) via GitHub Actions (`.github/workflows/deploy.yml`) on every push to the `main` branch and scheduled daily.

## Troubleshooting

- **Missing styles or broken images:** confirm the custom domain `vinu.world` is active in Settings → Pages.
- **Blog section shows "Could not load blog posts":** the Medium feed was unreachable during that build. Re-run the workflow.
- **Old preview image on LinkedIn or X:** the platforms cache previews. Use LinkedIn Post Inspector to refresh.
- **Workflow permission error:** under **Settings → Actions → General → Workflow permissions**, allow workflows to read repository contents. The workflow declares `pages: write` and `id-token: write`.
- **Build fails:** open the failed run, expand the `Install dependencies` or `Build site` step, and read the first error.
